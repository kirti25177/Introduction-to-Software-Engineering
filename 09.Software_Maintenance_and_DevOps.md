# Software Maintenance and DevOps

## 1. What Is Software Maintenance?

Software maintenance means updating software after its release to fix problems, improve performance, or meet new requirements.

**Example:** Updating a college attendance system to fix a bug or add a new report feature.

## 2. Types of Software Maintenance

### 1. Corrective Maintenance
Fixes errors or bugs found after release.

**Example:** Fixing a login feature that does not work.

### 2. Adaptive Maintenance
Changes software to work in a new environment.

**Example:** Updating an application to support a new operating system.

### 3. Perfective Maintenance
Improves performance or adds features based on user needs.

**Example:** Adding a search feature to an application.

### 4. Preventive Maintenance
Makes changes to reduce the chance of future problems.

**Example:** Refactoring confusing code to make it easier to maintain.

## 3. What Is DevOps?

DevOps combines **Development (Dev)** and **Operations (Ops)**.

It is a set of practices that helps teams develop, test, release, and maintain software more efficiently through collaboration and automation.

**Example:** Automatically testing an application and deploying a new version when approved changes are merged.

## 4. Why Is DevOps Important?

- Speeds up software delivery.
- Improves collaboration between teams.
- Automates repetitive tasks.
- Helps detect problems earlier.
- Supports reliable releases.
- Makes software updates easier.

## 5. Common DevOps Practices

### 1. Continuous Integration (CI)
Developers frequently merge code changes into a shared repository, where automated checks can run.

### 2. Continuous Delivery (CD)
Keeps software ready for release through automated build, testing, and delivery processes.

### 3. Continuous Deployment
Automatically releases changes to production when they pass the required checks.

### 4. Monitoring
Tracks software performance and errors after deployment.

## 6. Common DevOps Tools

| Tool | Purpose |
|---|---|
| Git | Tracks changes in source code |
| GitHub | Hosts repositories and supports collaboration |
| Jenkins | Automates build and testing workflows |
| Docker | Packages applications and their dependencies into containers |
| Kubernetes | Helps manage containerized applications |
| GitHub Actions | Automates workflows such as testing and deployment |

## 7. Software Maintenance vs. DevOps

| Software Maintenance | DevOps |
|---|---|
| Focuses on updating and supporting released software. | Focuses on collaboration and improving software delivery and operations. |
| Includes fixing bugs and improving features. | Includes automation, deployment, and monitoring. |
| Continues throughout the software's useful life. | Supports the ongoing development and operation of software. |

## 8. Key Takeaways

- Software maintenance keeps software useful after release.
- Corrective maintenance fixes bugs.
- Adaptive maintenance handles environmental changes.
- Perfective maintenance improves features and performance.
- Preventive maintenance reduces future problems.
- DevOps encourages collaboration and automation.
- CI, Continuous Delivery, and Continuous Deployment help streamline software releases.
