# Software Engineering: Case Studies and Interview Questions

## 1. Case Study: College Attendance Management System

Imagine a college wants to replace its manual attendance registers with software.

### Problem
- Teachers spend too much time marking and managing attendance.
- Students cannot easily check their attendance percentage.
- Manual calculations can lead to errors.

### Proposed Solution
Develop an attendance management system where:
- Teachers can mark attendance online.
- Students can view their attendance records.
- The system automatically calculates attendance percentages.
- Administrators can manage student and teacher accounts.

### Software Engineering Process

1. **Planning:** Identify the problem, goals, budget, and timeline.
2. **Requirements Analysis:** Understand what students, teachers, and administrators need.
3. **Design:** Plan the database, user interface, and system structure.
4. **Implementation:** Write the code.
5. **Testing:** Check attendance calculations, login functionality, and other features.
6. **Deployment:** Make the system available to the college.
7. **Maintenance:** Fix bugs and add improvements when needed.

### Possible Test Cases

| Test Case | Expected Result |
|---|---|
| Teacher marks a student present | Attendance is saved |
| Student opens their attendance page | Correct attendance is displayed |
| Attendance percentage is calculated | Correct percentage is shown |
| User enters an incorrect password | Login is rejected |
| Teacher submits attendance twice | Duplicate records are prevented |

## 2. Case Study: Online Shopping Website

Imagine a company wants to build an online shopping website.

### Main Features
- User registration and login
- Product search
- Shopping cart
- Online payment
- Order tracking

### Software Engineering Challenges
- Protecting customer information
- Handling many users at the same time
- Preventing incorrect payments
- Maintaining website performance
- Testing the complete order process

### Suitable Approach
An **Agile approach** can be useful because the team can develop features in small parts, collect feedback, and improve the website regularly.

For example:
- Sprint 1: User registration and login
- Sprint 2: Product listing and search
- Sprint 3: Shopping cart
- Sprint 4: Payment and order tracking

## 3. Common Software Engineering Interview Questions

### Q1. What is Software Engineering?

Software Engineering is a systematic approach to designing, developing, testing, deploying, and maintaining software.

### Q2. What is the difference between programming and Software Engineering?

Programming mainly involves writing code. Software Engineering includes the complete process of building and maintaining reliable software.

### Q3. What is SDLC?

SDLC stands for Software Development Life Cycle. It describes the stages followed to develop software, from planning to maintenance.

### Q4. What are the main phases of SDLC?

The main phases are:
1. Planning
2. Requirements Analysis
3. Design
4. Implementation
5. Testing
6. Deployment
7. Maintenance

### Q5. What is a software development model?

A software development model defines how the stages of software development are organized and carried out.

Examples include Waterfall, Iterative, Incremental, Spiral, V-Model, Prototype, and Agile.

### Q6. What is the Waterfall Model?

The Waterfall Model follows a sequential approach. Each phase is generally completed before the next phase begins.

### Q7. What is Agile?

Agile is an approach to software development that focuses on small, frequent releases, collaboration, feedback, and adapting to change.

### Q8. What is the difference between verification and validation?

- **Verification:** Are we building the product correctly according to its specifications?
- **Validation:** Are we building the right product for the user's needs?

### Q9. What is software testing?

Software testing checks whether software behaves as expected and helps identify defects.

### Q10. What is the difference between functional and non-functional requirements?

- **Functional requirements:** Describe what the software should do.
- **Non-functional requirements:** Describe how well the software should work, such as its performance, security, and reliability.

### Q11. What is software maintenance?

Software maintenance involves fixing bugs, adapting software to changes, and improving its performance or functionality after release.

### Q12. What is DevOps?

DevOps combines development and operations practices to improve collaboration and automate software delivery and maintenance.

### Q13. What is the difference between a bug and a failure?

- **Bug:** A defect in the software.
- **Failure:** When the software behaves incorrectly during execution.

### Q14. What is a test case?

A test case contains the inputs, conditions, and expected results used to check a particular software feature.

### Q15. What is the difference between unit testing and integration testing?

- **Unit testing:** Tests an individual component or function.
- **Integration testing:** Tests whether multiple components work correctly together.

## Key Takeaways

- Software Engineering involves more than just writing code.
- Requirements and design help guide development.
- Testing helps improve software quality and reliability.
- Agile supports continuous feedback and improvement.
- Maintenance keeps software useful after deployment.
- Real-world projects apply several Software Engineering concepts together.
