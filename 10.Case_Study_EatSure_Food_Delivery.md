# EatSure — Food Delivery System
### Software Engineering Case Study

A college Software Engineering assignment focused on requirements specification, system modelling, and software testing for an online food-delivery application.

## Overview

EatSure is a proposed online food-delivery platform that allows users to browse restaurants, search for food, add items to a cart, place orders, make payments, and track deliveries.

This case study documents the software engineering activities used to analyse and model the system, from defining requirements to designing diagrams and preparing test cases.

> **Project scope:** This repository documents the academic analysis, design, and testing work completed for the assignment. It does not claim that a complete production-ready food-delivery application has been deployed.

## Objectives

- Define the system's functional and non-functional requirements.
- Identify the main users and system interactions.
- Represent system processes using software design diagrams.
- Develop test cases for important application features.
- Explore software testing techniques and test coverage.

## Software Engineering Activities

| Activity | What it demonstrates |
|---|---|
| Software Requirements Specification (SRS) | Defining the system scope, features, constraints, and requirements |
| Data Flow Diagrams (DFD) | Representing how data moves through the system |
| Structure Chart | Showing the hierarchical organisation of system modules |
| Use Case Diagram | Representing interactions between actors and system functionality |
| Class Diagram | Modelling classes, attributes, operations, and relationships |
| Activity Diagram | Representing the flow of activities and decisions |
| Test Suite | Defining test inputs, expected results, and outcomes |
| Test Coverage Analysis | Examining statement, branch, path, and condition coverage |

## Main System Features

- User registration and login
- Restaurant browsing and search
- Food selection and cart management
- Order placement and cancellation
- Online payment
- Order tracking
- Ratings and reviews
- Personalised food recommendations
- Scheduled group ordering

These features are based on the requirements documented in the assignment.
