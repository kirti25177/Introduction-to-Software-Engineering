# Software Design and Architecture

## 1. What Is Software Design?

Software design means planning how software will be built before writing the code.

**Example:** Planning the login page, attendance page, and database of a college management system.

## 2. What Is Software Architecture?

Software architecture describes the overall structure of software and how its main parts work together.

**Example:** An online shopping application has a frontend, backend, and database.

## 3. Software Design vs. Software Architecture

| Software Design | Software Architecture |
|---|---|
| Focuses on the details of individual parts. | Focuses on the overall structure. |
| Explains how a feature works. | Explains how major components connect. |
| Example: Designing a login function. | Example: Connecting the frontend to the backend. |

## 4. Principles of Good Software Design

### 1. Modularity
Dividing software into smaller parts called modules.

**Example:** Separate modules for login, attendance, and reports.

### 2. Abstraction
Showing only important details and hiding unnecessary complexity.

**Example:** Clicking a button to download a report without knowing how it works internally.

### 3. Encapsulation
Keeping data and related functions together while controlling access to the data.

**Example:** A student class stores student details and provides methods to access them.

### 4. Reusability
Using the same code or component in different places.

**Example:** Using the same login component on multiple pages.

### 5. Maintainability
Making software easy to fix, understand, and update.

**Example:** Organizing code into separate files with meaningful names.

## 5. Common Software Architecture Types

### 1. Layered Architecture
Software is divided into layers, and each layer has a specific job.

- **Presentation Layer:** Displays information to users.
- **Business Logic Layer:** Handles application rules.
- **Data Access Layer:** Handles communication with the database.
- **Database:** Stores information.

### 2. Client-Server Architecture
The client sends a request, and the server processes it and sends a response.

**Example:** A browser requests a webpage from a web server.

### 3. Microservices Architecture
Software is divided into small, independent services that work together.

**Example:** An online shopping application may have separate services for payments, orders, and products.

## 6. What Is a Design Pattern?

A design pattern is a reusable solution to a common software design problem.

**Examples:**
- **Singleton:** Allows only one instance of a class.
- **Factory:** Helps create objects.
- **Observer:** Notifies objects when something changes.

## 7. Why Are Software Design and Architecture Important?

- Make software easier to understand.
- Help organize large projects.
- Make code easier to maintain.
- Allow code to be reused.
- Make future changes easier.

## 8. Key Takeaways

- Software design explains how individual parts work.
- Software architecture explains the overall structure.
- Modularity divides software into smaller parts.
- Abstraction hides unnecessary complexity.
- Layered, client-server, and microservices are common architecture types.
- Design patterns provide reusable solutions to common problems.
