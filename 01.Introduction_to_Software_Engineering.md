# Introduction to Software Engineering

## 1. What Is Software?

Software is a set of programs and instructions that tells a computer what to do.

**Examples:**
- Windows
- WhatsApp
- Instagram
- Google Chrome
- Visual Studio Code

## 2. What Is Software Engineering?

Software Engineering is the process of planning, designing, developing, testing, and maintaining software.

**Example:** When creating a college management system, developers plan its features, write code, test it, and fix problems.

## 3. Why Do We Need Software Engineering?

Software Engineering helps us to:

- Build good-quality software.
- Complete projects on time.
- Reduce errors and costs.
- Manage large projects.
- Work effectively in teams.
- Maintain and update software easily.

## 4. Programming vs. Software Engineering

| Programming | Software Engineering |
|---|---|
| Focuses on writing code. | Covers the complete software development process. |
| Solves coding problems. | Includes planning, design, coding, testing, and maintenance. |
| Can be done individually. | Often involves teamwork. |

**Remember:** Programming is one part of Software Engineering.

## 5. Characteristics of Good Software

Good software should have these qualities:

1. **Correctness:** Gives the expected result.
2. **Reliability:** Works properly and consistently.
3. **Efficiency:** Uses time and resources well.
4. **Maintainability:** Is easy to update and fix.
5. **Usability:** Is easy to use.
6. **Security:** Protects data from unauthorized access.
7. **Scalability:** Can handle an increase in users or workload.

## 6. What Is SDLC?

SDLC stands for **Software Development Life Cycle**.

It is a step-by-step process used to develop software, from planning to maintenance.

### Common Phases of SDLC

1. **Planning:** Decide what software to build.
2. **Requirement Analysis:** Understand what users need.
3. **Design:** Plan how the software will work.
4. **Implementation:** Write the code.
5. **Testing:** Find and fix errors.
6. **Deployment:** Make the software available to users.
7. **Maintenance:** Fix problems and improve the software.

## 7. Software Development Models

Software development models describe how the different SDLC phases are organized.

Common models include:

- **Waterfall Model:** Work is completed phase by phase in sequence.
- **Iterative Model:** Software is improved through repeated cycles.
- **Incremental Model:** Software is developed and delivered in smaller parts.
- **Spiral Model:** Development focuses on identifying and managing risks.
- **Agile Model:** Software is developed in small steps with regular feedback.

## 8. Software Engineering in Real Life

Consider building a college attendance management system.

- **Planning:** Decide why the system is needed.
- **Requirement Analysis:** Decide what features are required.
- **Design:** Plan the screens and database.
- **Implementation:** Write the code.
- **Testing:** Check whether attendance is recorded correctly.
- **Deployment:** Make the system available to the college.
- **Maintenance:** Fix bugs and add improvements.

## 9. Key Takeaways

- Software is a collection of programs and instructions.
- Software Engineering covers the complete software development process.
- Programming is one part of Software Engineering.
- Good software should be reliable, secure, and easy to maintain.
- SDLC helps organize software development into different phases.
- Different development models follow different approaches.
